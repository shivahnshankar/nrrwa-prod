{{< initiative title="ಬೇಲಿ" image="/assets/images/news/2026/drc_park/1.jpg" align="right" >}}
ಅಲೆಮಾರಿ ದನಗಳಿಂದ ಗಿಡಗಳನ್ನು ರಕ್ಷಿಸಲು ಪಾರ್ಕ್‌ನ ಎರಡು ಬದಿಗಳಲ್ಲಿ ಬೇಲಿ ಅವಶ್ಯಕವಾಗಿತ್ತು. ಬಣ್ಣ ಹಚ್ಚುವ ಕೆಲಸ ಬಿಟ್ಟು ಉಳಿದ ಕೆಲಸ ಪೂರ್ಣಗೊಂಡಿದೆ.
{{< /initiative >}}

{{< initiative title="ನಡಿಗೆ ಮಾರ್ಗ" image="/assets/images/news/2026/drc_park/2.jpg" align="left" >}}
ನಡಿಗೆ ಮಾರ್ಗ ಗುರುತಿಸಲಾಗಿದೆ, ಕೆಲವು ತಾಣಗಳನ್ನು ಹೊರತುಪಡಿಸಿ 3 ಇಂಚು ಮಣ್ಣು ತೆಗೆದು ಜಲ್ಲಿ ಹಾಕಲಾಗಿದೆ. ರೋಲಿಂಗ್ ಕೆಲಸ ಬಾಕಿ ಇದೆ.
{{< /initiative >}}

{{< initiative title="ದುರಸ್ತಿ" image="/assets/images/news/2026/drc_park/3.jpg" align="right" >}}
ಹಿಂದಿನ ಕಟ್ಟಡ ರಚನೆಗಳನ್ನು ಅಗತ್ಯವಿದ್ದಲ್ಲಿ ದುರಸ್ತಿ ಮಾಡಲಾಗಿದೆ. ಹೂವಿನ ಸಸಿಗಳನ್ನು ನೆಡಲು ನೀರಿನ ಮಾರ್ಗಗಳನ್ನು ಕೆಂಪು ಮಣ್ಣಿನಿಂದ ತುಂಬಲಾಗಿದೆ.
{{< /initiative >}}

{{< initiative title="ಸೇತುವೆ" image="/assets/images/news/2026/drc_park/4.jpg" align="left" >}}
ಜಪಾನೀ ಸೇತುವೆ, ಮೆಟ್ಟಿಲು ಮತ್ತು ರೇಲಿಂಗ್‌ಗಳನ್ನು ದುರಸ್ತಿ ಮಾಡಲಾಗಿದೆ. ರಚನೆಗಳಿಗೆ ಬಣ್ಣ ಹಚ್ಚುವ ಕೆಲಸ ಬಾಕಿ ಇದೆ.
{{< /initiative >}}

{{< initiative title="ಸ್ವಚ್ಛತೆ" image="/assets/images/news/2026/drc_park/5.jpg" align="right" >}}
ಪೊದೆಗಳನ್ನು ತೆರವುಗೊಳಿಸುವ ಪ್ರಮುಖ ಕೆಲಸ ಮುಗಿದಿದೆ.
{{< /initiative >}}
